# Route Sweden → Spain

Trip plan map, shared with family and friends. Static page built with [Leaflet](https://leafletjs.com) on OpenStreetMap tiles.

## Files

- `index.html` – the page
- `routes.json` – route waypoints (edit this)
- `places.json` – standalone markers
- `routes.js` – generated by `build.py`, loaded by the page
- `build.py` – snaps the waypoints to roads with OSRM and writes `routes.js`

## Editing

```sh
python3 build.py              # after changing routes.json or places.json
python3 -m http.server 8765   # preview at http://localhost:8765
```

Routes are approximate and use a car profile, not a motorcycle one.
